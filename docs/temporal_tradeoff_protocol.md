# Temporal 组件允许取舍的评估原则

本记录依据用户的新要求：五项指标允许取舍，其他模块可以参与弥补损失。
此前“所有五项同时胜过 v1”的结果保留，作为旧规则下的历史记录；
它们不再直接决定一个 temporal 组件是否有进一步整合价值。
本次只更新评估原则和候选解释，没有新增训练或改变任何 checkpoint。

五项统计口径继续保持不变，误差单位均为原图视差像素：

| 指标 | 固定定义 | 主要用途 |
|---|---|---|
| 全 GT 惩罚 EPE | 在有效 GT 上平均绝对视差误差；有效预测误差截断到 10，无效预测罚 10 | 完整系统的逐帧精度 |
| temporal 残差 | 预测的跨帧变化减去 GT 的跨帧变化，求绝对误差；在 GT 可对应区域统计，截断/无效惩罚为 10 | 时序变化是否正确，避免用过度平滑换取假稳定 |
| 好像素受损率 | 原 A5 误差 <0.1 的像素中，新误差比 A5 增加 >0.1 的比例 | 对原本正确区域的破坏 |
| 新增大退化率 | 全部有效 GT 中，新误差比原 A5 增加 >5 的比例 | 严重错误风险；“新增”相对于 A5，另报相对于 v1 新增/消除的事件 |
| 固定机会恢复率 | 固定在原历史有效且比原 A5 准确 >0.1 的区域，统计新输出比 A5 准确 >0.1 的比例 | 原本有历史可用的机会是否被利用 |

组件阶段以 temporal 和可恢复区域的收益为主要筛选依据，同时保留
逐帧误差、好像素损伤、大退化的代价和分区。允许有明确价值的取舍进入
融合训练；不再将任一项变差直接等同于组件无效。没有新设一个任意的
加权总分，也没有把历史 FAIL 改写为已验证成功。

最终整合阶段仍同时报告五项，并用同等训练预算的完整系统对照判断
整体收益。一个可执行的首轮对照是：

- 原 A5/VGGT + v1 temporal 分支 + 可训练融合模块。
- 相同 A5/VGGT、融合结构、初始化、数据和预算，仅更换 temporal 候选。

先训练融合部分，必要时再单独验证 VGGT 相关部分的联合训练。保留
当前预测与历史候选的独立输入和置信证据，让融合层能够选择可靠来源。
最终再检查预期的互补是否实际发生；五项也不恢复为自动“全赢”条件。

重要的当前边界：A5 已开启 VGGT dense features、geometry 和 gauge。
此前实验冻结 A5，并在最终输出之后加入 temporal 修正。因此，VGGT
现在已经存在，但不会自动修复后加模块引入的错误。所谓“由 VGGT 弥补”
是下一步需要通过改变融合接口或联合训练验证的假设。

根据已有训练结果，重新列入整合候选：

- residual_matching_control：整体 EPE、temporal 和恢复率点估计更好，
  好像素受损率上升，>5 px 退化率略升。
- residual_ambiguity_control：temporal、恢复率和 >5 px 退化率点估计更好，
  整体 EPE 略升，好像素受损率上升。

两者的 temporal 改善都很小，按序列 bootstrap 区间跨零。它们是值得
做整合对照的候选，还不是已确认的时序改进。完整数字与来源见
reports/temporal_tradeoff_review_20260907/review.json。

后续用户澄清要求改变设计，而不是继续采用输出修正头。上面的 residual
候选保留为历史取舍分析，不再作为新架构的实现路线。新的结构方案和对照
见 `docs/native_temporal_stereo_protocol.md`。
