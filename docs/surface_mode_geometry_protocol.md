# 表面概率聚合：受控设计验证

前两轮已完成真实训练和全量验证，均未超过 v1 的核心 temporal/恢复能力。
第二轮 memory 模型的固定机会候选可恢复率达到 95.2199%，实际恢复率
只有 22.0008%，单个历史标签被选中的比例为 0.0143%。原训练目标包含
正确候选集合的总概率，而逐像素 WTA 只比较单个标签；同一表面的多个
近似等价历史位置可能分摊概率。独立候选的硬选择也不能直接融合相近估计。
这些是继续进行本对照的实证与结构依据，不声称概率分摊解释全部误差。

本轮保留候选产生、匹配证据、网络参数量、递归历史和图像输入接口，比较：

| 组别 | 概率到几何的解码 |
|---|---|
| wta | 单个标签最大分数，作为同预算控制 |
| mode_pool | 汇总邻近表面候选的概率，选择表面，再在该表面内归一化融合 |

mode_pool 对每个候选中心累加 ±2 HR px 范围内有效候选的概率，选取
概率质量最大的中心；最终只融合该中心 ±2 px 内的候选。融合成员的
视差跨度至多 4 px，因此相隔超过 5 px 的前景/背景候选不会被一起平均。
这不是对最终 A5/v1 预测加残差，而是修改新几何解码器的表示和决策规则。
该规则是针对观测失败提出的设计假设，并非完整 NMRF 论文方法。

两组从同一个已完成的 hypothesis memory 2,000 步 checkpoint 初始化，
各继续 2,000 步，8 GPU、seed 42、同样的 845/307 训练/开发划分和抽样。
AdamW LR=1e-4、余弦降到 0.1 倍、weight decay=0.01、梯度裁剪 1，固定
最终步，不按验证结果挑选 checkpoint。

两组共享同一监督改动：候选分类监督对距 GT 小于 1 px 的正确表面估计
累加概率；没有此类候选时才使用最接近 GT 的集合。不再强制选某一个
近似等优的当前标签。其余逐像素期望误差、条件回归、恢复/拒绝、退化及
GT 时序损失保持一致。wta/mode_pool 的差值隔离解码规则；相对第二轮
2,000 步结果的差值还包含新的共享监督和继续训练，不能全部归给聚合。

验收仍为全部原 1,294 个端点、五项固定分母及安全/边界/动态指标，允许
组件取舍。对聚合模型额外报告历史权重和实际参与率；一个模式的中心
可能来自当前帧，因此“中心是否为历史”不能代替历史参与率。
所有结论来自实训与完整评估，本轮仍是反复检查过的开发基准。
