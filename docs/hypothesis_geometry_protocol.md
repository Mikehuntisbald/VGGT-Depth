# 保留表面候选的几何解码：实证动机和训练协议

这轮直接替换 A5 的几何解码器，不读取 A5/v1 的最终预测或修正头。
前一轮把历史放入 FFS 匹配初始化及隐状态，两组新结构和 late 对照各训练
1,000 步。固定失败点追踪进一步发现，单纯前移历史没有消除信息丢失：

- index 2，(253,147)：GT=99.25；FFS 输出约 99.15，左右有效性筛选后
  的固定几何锚点约 21.05，最终约 21.03。原两级有界更新最多放大
  exp(0.5)=1.6487，无法从该锚点恢复到正确表面。
- 同一例的 8×8 粗网格中心 (252,148) 的真实 GT 是 14.421875。
  用一个中心 GT 监督整个单元的单一视差，不能代表邻近前景像素 99.25。
- index 29，(570,20)：GT=100.3125；迭代视差约 98.17，后续上采样
  主要选择约 13 px 的背景邻居，得到约 35 px。正确表面在候选中存在。

证据保存在 native_temporal_stereo_20260907/stage_traces.json。
本设计是在检查这些开发失败点后提出的，不属于未接触验证集的独立确认。

## 结构

参考 [NMRF, CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Guan_Neural_Markov_Random_Field_for_Stereo_Matching_CVPR_2024_paper.pdf)
在保留候选后分别解码 8×8 像素的偏移和分数、最后逐像素选择的机制。
官方代码版本 a50bd8f407ae481c38f95cf141e1b5256e962cb7；此处不是完整
NMRF 的 DPN、变分推断或细化模块复现。

FFS/VGGT 仍作为共同冻结的视觉骨干。保留每帧的 FFS 视差初值、图像双目
观测、左右学习特征和独立因果 VGGT 特征，直接送入新解码器：

1. 每像素保留 23 个候选：图像双目观测、标定后的 VGGT、9 个邻近 FFS
   粗初值、3 个不相邻的特征相关峰，以及 9 个局部历史候选。
2. 历史来自本模型自身上一帧输出，只进行可见性投影和 ±1/±2 HR 像素
   局部位置查询，不用当前深度做提前硬否决。
3. 候选以双目学习特征、逐像素光度/LR 残差、历史光度/置信、VGGT 和
   完整 8×8 RGB 内容为证据。候选嵌入之间及空间邻域之间交换信息。
4. 每个候选分别预测单元内 64 个像素的分数和 ±4 HR px 偏移；最终
   每像素选择一个表面，不平均远隔的前景与背景视差。
5. 有效性、不确定性及下一帧状态由新解码器产生。没有旧几何输出锚点，
   也没有对 A5 最终输出加残差的路径。VGGT 标尺只由冻结图像双目证据
   估计并截断梯度，避免离散候选的代理梯度反过来改变全局标尺。

FFS 原始图像双目观测是骨干输出，不是 A5 的联合几何预测。训练时通过
mmap 读取这些冻结观测和特征，跳过无用的巨大三维代价体；原图检查会
重新执行冻结骨干并要求输入、输出逐像素一致。

## 受控训练与验收

两组使用完全相同的新解码器、初始化、参数量、数据顺序、每帧因果 VGGT：

| 组别 | 显式视差历史 |
|---|---|
| no_memory | 历史候选缺失；保留相同网络容量 |
| memory | 自身递归历史与局部对齐候选 |

两组各训练 2,000 步、8 GPU、每卡一个完整 8 帧片段；845 个优化端点、
307 个训练集开发端点；seed=42。新解码器从头初始化，AdamW LR=1e-4，
weight decay=0.01，梯度裁剪 1，余弦降至 0.1 倍，固定最终 checkpoint。
不将它与前一轮 1,000 步对照的差值解释成纯架构效应；显式历史的增量
由本轮同预算 no_memory/memory 对照判断。

末两帧使用真实 Spring 逐像素 GT，包含候选期望误差、成功集合监督、
条件偏移回归、单独归一化的恢复/拒绝、大退化惩罚、GT 时序残差和质量
监督。粗单元内不同表面的 GT 都保留，禁止改用一个中心 GT 代表整单元。

全量验收仍使用原 1,294 个端点及固定五项指标、原机会和安全分母；允许
组件取舍，另报候选可恢复比例、真正恢复比例、边界/动态表现和大退化代价。
必须完成真实训练、全量评估、原图/缓存及独立因果前缀检查后才能形成有效性结论。
